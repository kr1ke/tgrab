# tgrab

[English](README.md) · **Русский**

*(читается «ти-грэб» — `tg` + `grab`)*

Загрузчик медиа из Telegram, который оставляет после себя нормальный архив.

---

## Проблема

[tdl](https://github.com/iyear/tdl) — отличный загрузчик. Вот что он отдаёт на выходе:

```
1234567890_42_98765432109876.mp4
```

ID канала, ID сообщения и внутренний ID файла в Telegram. Три числа, по которым невозможно
понять, что внутри. Скачай полсотни таких — получишь кучу, в которой ничего не найти.

Ещё у него есть прогресс-бар, которого ты никогда не увидишь: при вызове из скрипта вывод
буферизуется, и ты две минуты смотришь в молчащий терминал.

## Что делает tgrab

```
2026-08-12_11-53_Разбор-балансировщика_42.mp4
```

Дата и время публикации, подпись поста и ID сообщения — чтобы файл всегда можно было
сопоставить со ссылкой `t.me/c/<канал>/<msg_id>`.

- **Читаемые имена** — из даты поста и подписи, а не из числовых ID
- **Выгрузка канала целиком** — экспортировать список сообщений и забрать одной командой
- **Видимый прогресс** — статус-строка, за которой реально можно следить
- **Любой чат Telegram** — приватный, защищённый, публичный, группы, «Избранное»

## Статус

**Ранний прототип.** Сейчас это набор shell-скриптов вокруг `tdl`, вынутый из рабочей связки.
Бинарника `tgrab` пока нет — CLI и приложение это план, а не текущее состояние. Интерфейс
считать нестабильным.

## Требования

- macOS (Linux должен работать, но не проверялся)
- [tdl](https://github.com/iyear/tdl) v0.20+ в `PATH`
- `ffmpeg` (нужен `ffprobe` для проверки скачанного)
- Telegram Desktop с активным входом — сессия импортируется из него

## Установка

Ставить из релизов на GitHub и **обязательно сверять контрольную сумму**. Homebrew не подойдёт:
тап `iyear/tap` удалён из upstream.

```bash
V=$(curl -sSL https://api.github.com/repos/iyear/tdl/releases/latest | sed -n 's/.*"tag_name": "\(.*\)".*/\1/p')
cd "$(mktemp -d)"
curl -sSLO "https://github.com/iyear/tdl/releases/download/$V/tdl_MacOS_arm64.tar.gz"
curl -sSLO "https://github.com/iyear/tdl/releases/download/$V/tdl_checksums.txt"
shasum -a 256 -c tdl_checksums.txt --ignore-missing
tar xzf tdl_MacOS_arm64.tar.gz && mkdir -p ~/.local/bin && cp tdl ~/.local/bin/
```

Дальше склонировать этот репозиторий и положить `bin/` куда удобно.

## Использование

**1. Авторизоваться.** Сначала закрыть Telegram Desktop — tdl читает его папку `tdata`.

```bash
tdl login -T desktop
```

Выбрать аккаунт, нажать Enter. Если стоит локальный код-пароль — добавить `-p <код>`.
Импорт переиспользует существующий ключ сессии, а не создаёт новое устройство: в
Settings → Devices ничего нового не появится.

**2. Скачать.** Уходит в фон и пишет лог, который читает статус-строка.

```bash
./bin/dl.sh "https://t.me/c/<channel_id>/<msg_id>" ~/Videos
```

**3. Следить.**

```bash
./bin/progress.sh
```

```
⏳ соединение с Telegram…
⬇  47.3% [███████████░░░░░░░░░░░░░] 120.42 MB · 2.11 MB/s · осталось 1м03с
✓ готово — 254.49 MB за 2м01с (2.10 MB/s)
```

Коды возврата: `0` идёт, `3` завершено, `4` ошибка — чтобы можно было крутить цикл опроса.

**4. Подчистить.** Ключ авторизации лежит в `~/.tdl` открытым текстом.

```bash
rm -rf ~/.tdl
```

## Шаблон имени файла

Задаётся через `--template` у tdl, переопределяется переменной `$TG_TEMPLATE`:

```
{{ formatDate .MessageDate "2006-01-02_15-04" }}_{{ if .FileCaption }}{{ filenamify .FileCaption 60 }}_{{ end }}{{ .MessageID }}
```

Дата — время **публикации**, а не скачивания: так архив сортируется по смыслу, а повторное
скачивание даёт то же самое имя. Подпись поста — единственное человекочитаемое поле, которое
отдаёт Telegram: `.FileName` там обычно безликое число, а читаемого названия канала в шаблоне
нет вовсе, только числовой `DialogID`.

## Пакетная выгрузка

```bash
tdl chat export -c <chat> -T last -i 50 -o export.json
tdl dl -f export.json -d ~/Videos
```

`-T` определяет, как читается `--input`: `time` — диапазон unix-таймстемпов `начало,конец`,
`id` — диапазон номеров сообщений `min,max`, `last` — сколько последних медиа взять. Фильтр
`-f` принимает выражения вида `"Media.Size > 100*1024*1024 && Media.Name endsWith '.mp4'"`.
Список полей зависит от версии — свой смотреть через `tdl chat export -c <chat> -f -`.

## Грабли

Каждая стоила реального времени.

| Симптом | Причина |
|---|---|
| `brew install iyear/tap/tdl` → `Repository not found` | тап удалён, ставить из релиза на GitHub |
| `tdl login` → `Error: EOF` | выбор аккаунта интерактивный, нужен настоящий терминал |
| Файл «пропал», хотя tdl сказал `done!` | tdl ставит mtime **даты поста**, а не скачивания — `find -newermt` и `ls -lat` его не увидят. Искать по имени. |
| Размер ровно 1 МиБ или 128 МиБ | обрыв на границе буфера: файл битый, а не маленький |
| `timeout: command not found` | на macOS нет утилиты `timeout` |

## Безопасность

Импорт сессии из десктопа копирует **ключ авторизации** Telegram в `~/.tdl` открытым текстом.
Любой процесс с доступом к домашней папке — вредонос, синхронизируемый в облако бэкап — получает
полный доступ к аккаунту, и **2FA не спасает**: извлечённый ключ уже «за» ней. После работы
`~/.tdl` удалять.

Сверка контрольной суммы tdl доказывает лишь отсутствие подмены при передаче. Она не
подтверждает добросовестность издателя, и аудита бинарника никто не делал.

Telegram ограничивал и банил аккаунты за агрессивное использование стороннего API. Несколько
файлов — ничто, флажок поднимается на массовой выкачке. На больших задачах использовать
`--delay` и небольшой `-l`.

Ради одного файла проще открыть пост в Telegram Desktop и сохранить через правый клик →
*Save As*: нулевой дополнительный риск. tgrab нужен там, где такой способ перестаёт
масштабироваться.

## О лицензии

`tdl` распространяется под **AGPL-3.0**. tgrab вызывает его как отдельный исполняемый файл,
который ты ставишь сам, — это mere aggregation, производной работы не возникает. Если же
встроить или слинковать tdl во что-то, AGPL распространится на всё целиком, а её сетевая
оговорка ударит по хостируемым сервисам. Это не юридическая консультация — проверить стоит до
того, как архитектура застынет.

Файла лицензии в репозитории пока нет, а это по умолчанию означает «все права защищены».
Для публичного репозитория так обычно не нужно — стоит выбрать лицензию.
